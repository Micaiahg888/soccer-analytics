# Soccer Analytics Platform

## Run in your browser

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/Micaiahg888/soccer-analytics)

1. Sign in to GitHub and select **Create codespace**.
2. Wait for setup to finish. The Soccer Analytics preview should open automatically.
3. If the preview does not open, select **Ports** in the editor and open **Soccer Analytics** on port **5000**. Keep the port visibility set to **Private**.

Each new Codespace starts with an empty SQLite database. Use **Add Team** on the dashboard to create your first sample team.
